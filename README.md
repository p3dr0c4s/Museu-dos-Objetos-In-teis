# Museu dos Objetos Inúteis

Um museu virtual dedicado a objetos que provavelmente não precisavam de um museu.

O projeto é uma brincadeira feita com HTML, CSS e JavaScript, com a ideia de transformar coisas completamente comuns e inúteis em peças de uma exposição aparentemente séria.

## Sobre o projeto

A proposta é simples: entrar no museu, passar pelas salas e descobrir objetos que não têm absolutamente nada de especial.

Cada sala apresenta uma peça diferente, com informações sobre a obra e algumas interações.

Até agora, o museu possui:

* Sala 01 — A Colher
* Sala 02 — A Meia Solitária
* Sala 03 — A Pedra
* Sala 04 — O Clipe Administrativo
* Sala 05 — A Caixa Vazia

Cada objeto possui uma descrição própria e algumas interações diferentes.

## Funcionalidades

* Navegação entre as salas
* Contador de salas
* Animações de transição
* Objetos interativos
* Mensagens diferentes para cada objeto
* Interface inspirada em museus tradicionais
* Layout responsivo
* Pequenas piadas escondidas nas descrições e interações

## Tecnologias

O projeto foi feito utilizando apenas:

* HTML
* CSS
* JavaScript

O desenvolvimento foi feito no Visual Studio Code.

Não é necessário Node.js, banco de dados, frameworks ou qualquer configuração complicada para executar o projeto.

## Como executar

Baixe ou clone o projeto e abra o arquivo:

`index.html`

no navegador.

Também é possível abrir a pasta no Visual Studio Code e utilizar uma extensão como Live Server, caso já esteja instalada.

## Ideia

A ideia do projeto surgiu como uma forma de praticar desenvolvimento web criando algo simples, visual e, principalmente, divertido.

Em vez de fazer mais uma página genérica de portfólio ou uma lista de tarefas, a proposta foi criar um museu completamente desnecessário e tentar fazer até uma colher parecer uma peça histórica importante.

O projeto também serve como um exercício para experimentar HTML, CSS, JavaScript, animações, manipulação do DOM e interação com o usuário.

## Próximos passos

Algumas ideias:
